# 📊 Portafolio de Análisis y Ciencia de Datos

Bienvenido a mi portafolio técnico. Este repositorio centraliza mis proyectos orientados a la resolución de problemas de negocio mediante la ingeniería de datos, modelado de bases de datos relacionales y desarrollo de soluciones de Inteligencia de Negocios (BI).

## 🛠️ Tecnologías y Herramientas
* **Lenguajes de consulta y programación:** SQL, DAX, Python.
* **Procesamiento de datos:** Pandas, Power Query.
* **Plataformas y Motores:** SQL Server (SSMS), Power BI, Google Colab.

## 📁 Estructura del Repositorio

### 1. [Pipelines ETL con Python y Pandas](./01_ETL_Pandas_Colab)
Scripts modulares para la extracción, limpieza, transformación y validación de datos corporativos.
* **Caso Gestión de Flotas:** Tratamiento de valores nulos, estandarización de texto y generación de variables calculadas para vehículos de alquiler.
* **Caso Epidemiológico:** Normalización, deduplicación por DNI y validación estricta de rangos para registros clínicos.

### 2. [Modelado y Consultas SQL](./02_Proyecto_Base_de_Datos) *(En desarrollo)*
Diseño de bases de datos normalizadas (3NF) e implementación de lógica de negocio mediante consultas estructuradas, vistas y procedimientos almacenados en SQL Server. Incluye documentación técnica e informes de análisis.

### 3. Dashboards y Business Intelligence *(Próximamente)*
Desarrollo de modelos analíticos utilizando esquemas estrella. Implementación de cálculos avanzados con funciones DAX y diseño de reportes interactivos en Power BI enfocados en la optimización de procesos y toma de decisiones estratégicas.
